# Cubic / InHandReorient 初始姿态配置

启动 `experiment/inhand_reorient/configure_viser.ps1`，在浏览器打开
`http://127.0.0.1:8083`。工具只需要 Viser 和 URDF 依赖，不启动 Isaac Sim。

- 16 个关节滑条按 URDF 关节限位设置，界面单位为度。
- 方块位置用米表示；旋转输入为 XYZ 欧拉角，单位为度。
- 方块的三轴控件支持拖拽平移、旋转，并与数值输入双向同步。
- 六面使用不同颜色并显示局部坐标轴，方便辨认方块朝向。
- 方块的尺寸倍率仅用于预览；实际训练使用 0.82–0.88 倍尺寸随机化，对应边长 49.2–52.8 mm。

点击“保存初始姿态”后，配置保存到
`source/gex_learning/gex_learning/tasks/direct/inhand_reorient/config/initial_pose.json`。
JSON 以关节名记录弧度值，以环境局部坐标记录位置，以 wxyz 四元数记录方块朝向。
保存时检查有限数值、关节限位，并归一化四元数。

新启动的训练和回放会读取此配置，将保存的值应用于首次生成和每次 episode 重置，
关闭初始关节位置、方块位置及初始 Z 轴角度的随机偏移。
XYZ 目标采样、奖励、物体尺寸随机化和其他物理随机化仍由任务配置控制。
重置之后物体会正常受到物理作用；编辑器本身不验证抓握稳定性。

“重新载入已保存配置”丢弃当前未保存修改；“恢复原始随机初始化”停用保存姿态，
保留 JSON 中的姿态数据。初始交付配置处于停用状态，首次保存后才启用。
也可用 `env.use_initial_pose_config=False` 临时跳过配置文件。
自定义文件使用 `--config <JSON>`，训练时对应指定 `env.initial_pose_file=<JSON>`；
相对配置路径从仓库根目录解析。

验证结果：64 项 pytest 通过；真实 Isaac Lab 中使用修改后的关节位置、方块位置和
非单位姿态，4 个环境连续重置两次均正确，随后 8 步仿真观测和奖励保持有限。
通过 Viser 本地 WebSocket 协议验证了关节滑条、位置/旋转输入、三轴拖拽和保存回读，
测试使用独立 JSON，没有覆盖用户配置。浏览器自动启动被本机自动审批拦截，
未执行浏览器截图验收；可直接点击本地地址检查页面。
